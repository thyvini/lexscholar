# PDF test fixtures

These synthetic fixtures were created for LexScholar; they contain no research
materials or third-party documents. They may be reused and redistributed under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The valid PDFs were generated as minimal PDF 1.4 documents with two pages,
the standard Helvetica font and a short literal label. `valid-renamed.pdf` is
an exact copy of `valid.pdf`; `distinct.pdf` uses a different label. The
encrypted fixture was produced from `valid.pdf` with qpdf AES-256 encryption;
its user password is `fixture-password` and owner password is
`fixture-owner-password`. `corrupt.pdf` is deliberately truncated and
`not-a-pdf.txt` is plain text. Passwords are public test data.

## Summary reference set (F003)

`summary/*.pdf` are generated by `scripts/make-summary-fixtures.fsx`
(`dotnet fsi scripts/make-summary-fixtures.fsx`, PdfPig `PdfDocumentBuilder`, standard
Helvetica) and are released under CC0 1.0 like the rest. Page text is built from
short public-domain passages embedded in the script, repeated with a section number
so every page differs: the opening of *Pride and Prejudice* (Jane Austen) and of
*Moby-Dick* (Herman Melville) and the preamble of the US Declaration of Independence
(all via Project Gutenberg, https://www.gutenberg.org), and the opening of *Dom
Casmurro* (Machado de Assis, Portuguese, without accents; Project Gutenberg). The
files are not byte-reproducible (PdfPig writes a fresh document id), so regenerating
changes the hashes below; the committed files are the reference.
