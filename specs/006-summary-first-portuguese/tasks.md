# Tasks: F006 — Summary first, in Portuguese

**Feature**: F006 | **Inputs**: [spec](spec.md), [plan](plan.md), [research](research.md), [data model](data-model.md), [contracts](contracts/), [quickstart](quickstart.md), [mockups](mockups/README.md)

Each task is one vertical slice and one PR: tests first (meaningful RED, then GREEN), tagged `Trait("Task", "Txxx")`, run with `scripts/check.sh Txxx`. Design decisions are in `research.md` (Rn below); don't re-decide them. The look follows the mockups' tokens; the F007 parts listed in `mockups/README.md` are **not** built. Every new or changed text goes into `src/LexScholar.Client/Texts.fs` in Brazilian Portuguese, never as a literal in a view. Journeys select by role and accessible name from `Texts` (R5), run in Chromium and Firefox, and each slice migrates the English selectors of the screens it changes. `[P]`: the file list overlaps no slice that can run at the same time. Evidence: `evidence/txxx-<topic>.md`, then tick the task with a link.
