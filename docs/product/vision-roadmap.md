# Product vision and roadmap

LexScholar is a local workspace for one researcher to organize research
projects and a shared PDF library. It helps the researcher work with sources
and their summaries. Linux x86-64 and macOS ARM64 are mandatory target
platforms for future delivery, with Firefox and Chromium as target browsers.
Current shipped support remains Linux with Firefox and Chromium; macOS support
requires implementation and verification, not merely this roadmap decision.
The authoritative behavior of shipped features remains in their
specifications and the codebase guide, not in this roadmap.

## Direction

The following is the owner's v0.5.3 direction, not an implementation
specification or approval of every design decision:

| Feature | Direction | Status |
| --- | --- | --- |
| F007 | Read-only Google Docs | Planned direction; specify the boundary before implementation. |
| F008 | Large PDFs and local retrieval | Planned direction; specify the boundary before implementation. |
| F009 | Self-contained email readings taking 10–15 minutes | Planned direction; specify the boundary before implementation. |
| F010 | Notebook | Tentative. |
| F011 | Questions and answers | Tentative. |

Mobile and cloud work are outside the current direction. This is not permission
to add either to a feature. A future feature's approved specification decides
its actual scope; the roadmap does not create privacy, data-retention or
integration commitments.

The owner decides new scope and publication. See
[`decision-log.md`](decision-log.md) for delegated product authority.
